Input event log입력 이벤트 기록

For checking IME input (Korean, Japanese, Chinese) by hand. Every keydown, composition, and input event on the grid's input box is listed in order, with what the grid did after it.

한글 같은 조합 입력을 손으로 확인하는 페이지입니다. 그리드 입력칸의 keydown, compositionstart, compositionend, input 이벤트를 순서대로 찍고, 그 뒤 그리드 상태를 함께 보여 줍니다.

  • Click a cell in the Text column, switch to a Korean input method, type a word, and press Enter (or Tab, or an arrow key) while the last syllable is still being composed.
  • The grid should save once and move once. "Δms" is the time since the previous event by event.timeStamp; "prevented" means the grid called preventDefault().
  • Press Copy log and paste the result into the issue or the checklist (docs/ime-manual-check.md).
  • "글자" 컬럼의 셀을 누르고 한글 입력기로 바꾼 뒤, 낱말을 치고 마지막 글자를 조합하는 중에 Enter(또는 Tab, 방향키)를 누릅니다.
  • 그리드는 한 번 저장하고 한 칸만 움직여야 합니다. "Δms"는 앞 이벤트와의 event.timeStamp 차이, "prevented"는 그리드가 preventDefault()를 불렀다는 뜻입니다.
  • 기록 복사를 눌러 이슈나 확인표(docs/ime-manual-check.md)에 붙여 넣으세요.
